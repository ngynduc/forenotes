---
title: Tasks and notes
description: Coordinate investigation work without mixing temporary working notes with durable findings.
---

Tasks represent work that someone can own and complete. Use them for collection, analysis, containment, review, and stakeholder follow-up.

![Tasks board](/user-guide/tasks.png)

## Write actionable tasks

A useful task states the outcome, not merely the activity. Include the relevant scope, assign an owner or assignee, set priority, and add a due date when timing matters.

Use these statuses consistently:

| Status | Meaning |
| --- | --- |
| `todo` | Ready to begin. |
| `in_progress` | Someone is actively working it. |
| `blocked` | Progress requires another action or decision. |
| `done` | The stated outcome has been completed. |

## Keep working notes with the task

Task notes support Markdown and image attachments. Use them for commands, intermediate observations, handoff context, and analysis that is not yet a durable finding.

![Task notes](/user-guide/task-notes.png)

Promote stable facts into timeline, entity, indicator, or finding records. A closed task should not be the only place where important evidence or conclusions exist.

## Link work to evidence

Link a task to the records it acts on. This lets reviewers distinguish completed response work from unresolved evidence and makes the final report easier to validate.
