## A useful first session

After opening a new Forenotes installation:

1. Sign in with the bootstrap administrator and change the temporary password.
2. Create a case and add the people who should see it.
3. Create an incident inside the case.
4. Record a timeline event and a finding.
5. Link the finding to its supporting evidence.
6. Assign follow-up work and generate a report draft.

The [case-to-report guide](/docs/investigate/case-to-report/) walks through that sequence.
