Browse endpoints by tag, inspect parameters and schemas, and expand an operation to see its documented request and response examples. Download the [OpenAPI specification](/openapi.json) to use it with another client.

The API runs with the full Forenotes application. Swagger UI defaults to `http://localhost:8787`; select or edit the server to match your deployment. Sign in through `POST /api/auth/login` before trying endpoints that require the `forenotes_session` cookie.
