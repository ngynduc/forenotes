# Release regression checks against 0.2.5

Baseline: `v0.2.5` (`ec6bb42`).
Validation uses the in-memory demo data and synthetic fixtures.

Validated on 2026-11-27:

- `npm run lint`: passed.
- `npx vitest run --no-file-parallelism`: 33 test files passed and 1 optional
  test file skipped; 242 tests passed and 2 opt-in PostgreSQL concurrency tests
  skipped.
- `npm run build`: passed; TypeScript server and Vite client builds completed.
- Production Compose configuration: passed; services are `postgres` and `app`.
- `git diff --check`: passed.
- `actionlint`: not run (not installed on the validation host).
- Image build: `ngynduc/forenotes` built locally at 286 MB. The container
  started, `/api/health` returned `503` without a database, and `docker stop`
  completed in 220 ms.
- Live provider check against an OpenAI-compatible gateway: Test connection
  succeeded, and AI Report Chat streamed a reply after a tool lookup.
