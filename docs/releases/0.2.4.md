# Forenotes 0.2.4

Tag the validated `release/v0.2.4` commit as `v0.2.4` to publish both container
images. The release workflow validates the tag before publishing.

## Changes

- Fix the case member picker for case commanders with a case-scoped candidate
  directory. The admin user directory remains restricted to user managers.
- Clear the candidate directory when the signed-in user's global role changes.
- Shorten new browser sessions to four hours, with an absolute expiry that
  activity does not extend.
- Add account deletion under **Admin → Users → Edit → Delete**. Protect the
  current account, bootstrap administrator, last case commander, and accounts
  referenced by existing records. Successful deletion revokes browser sessions
  and MCP tokens and records an audit event.
- Preserve a case commander when account deletion runs concurrently with
  another commander deletion, member removal, or role demotion.
- Add an **Assigned to** switch to the relationship graph, disabled by default.
  Switching visibility preserves graph positions and other relationships.
- Exclude MITRE and custom tag nodes from the relationship graph. Record tags
  and the separate MITRE matrix remain available.

No new database migrations or dependency changes are required compared with
0.2.3. See the [regression validation record](./0.2.4-validation.md).

## Upgrade after publication

Wait for both image publishing jobs to succeed. Back up PostgreSQL, `/app/data`,
and `.env.production`, and preserve `FORENOTES_LLM_SECRET_KEY`.

Set these image pins in the existing `.env.production`. They override Compose
image defaults:

```dotenv
FORENOTES_IMAGE=ngynduc/forenotes:0.2.4
FORENOTES_REPORT_LLM_IMAGE=ngynduc/forenotes-report-llm:0.2.4
```

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml pull app report-llm-service
docker compose --env-file .env.production -f docker-compose.prod.yml up -d app report-llm-service
docker compose --env-file .env.production -f docker-compose.prod.yml ps
```

Both services should become healthy. Existing sessions retain their stored
expiry; sign out and back in to receive a new four-hour session. Verify the case
member picker, admin Delete action, and graph visibility switch after upgrading.

Installer and Compose defaults stay on published images during preparation.
Promote those defaults only after both 0.2.4 images are available.
